# 데모 각본

해커톤 데모 영상(Remotion)을 만들기 전에 합의할 것 — 무엇을 주장하고, 어떤
순서로 보여주고, 각 컷에 무엇이 담겨야 하는가.

**[demo-plan.html](demo-plan.html)** — 브라우저로 열어 보세요.

- 컨셉과 원칙 3개, 수집→추출→대기열→내 화면→동료로 이어지는 파이프라인 다이어그램
- 시나리오 4막 (수집 / 대기열 / 내 뷰 / MCP)
- 미디어 20슬롯 스토리보드, 목표 러닝타임 2분 35초
- 촬영 전 체크리스트

`screenshots/`의 이미지는 실제 앱에서 찍은 것입니다(리티나 1920×1640 →
1600px JPEG). 문서가 상대 경로로 참조합니다.

  핵심 기록에 같은 항목이 겹쳐 보입니다. 수정은 새로 들어오는 것만 막고
  이미 저장된 것을 소급해 합치지는 않습니다.
- **공개/비공개 확인** — 04막의 "권한 없음" 장면이 성립하려면 비공개로
  표시된 기록이 실제로 있어야 합니다.
