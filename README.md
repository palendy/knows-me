# knows-me

**세션만 썼을 뿐인데 나에 대한 정보가 남았다. 그걸 의도적으로, 더 상세하게 남긴다.**

## 시작점

Claude Code와 Codex를 쓰면서 세션만 진행했을 뿐인데, 에이전트에 나에 대한 정보가 남아 있었다. Codex의 메모리 기능도 같은 일을 한다.

그런데 남는 것은 에이전트가 알아서 고른 것이다. 정작 매번 다시 설명해야 하는 것들 — 시크릿 키가 어디 있는지, 내가 어떤 방식으로 일하는지 — 은 남지 않는다.

그래서 그 정보를 **더 상세하게, 의도적으로** 남기면 어떨지 해보는 것이 이 과제다.

## 챌린지

> **어떻게 나에게 반복 가능하고 필요한 정보만 잘 데이터베이스화할까.**

세 가지를 동시에 풀어야 한다.

| 문제 | 내용 |
|---|---|
| **반복 가능한 것 고르기** | 세션에는 일회성 대화가 대부분이다. 다음에도 또 쓰일 것만 골라야 한다 |
| **필요한 것만 남기기** | 에이전트가 자기 판단으로 모으면 좋은 것과 잡음이 섞인다 |
| **데이터베이스화** | 산문 메모가 아니라 구조가 있어야 한다. 출처·확인 여부·유효기간이 붙어야 믿을 수 있다 |

## 방법

에이전트는 **후보만 고른다.** 후보는 **Queue**에 들어간다. 내가 확인한 것만 맥락 DB에 들어간다.

Queue 항목은 두 종류다.

- **사실 후보** — "이 프로젝트는 `./run.sh`로 띄우는 것 맞나요?"
- **질문** — 에이전트가 나에 대해 궁금한 것, 맥락이 더 필요한 것

나는 시간 날 때 Queue를 보고 답한다. 처음 한 번은 목록을 일괄로, 이후는 세션이 끝날 때마다 하나씩.

## 목표

세션을 열면 Claude가 두 가지를 설명 없이 안다.

1. **이 폴더의 프로젝트 사정** — 리포, 기동, 테스트, 규칙, 시크릿 위치
2. **나의 일하는 방식** — 언어, 선호, 금지 사항

## 구성

```
활동 소스 ──▶ 후보 추출 ──▶ Queue ──▶ 내가 확인 ──▶ 맥락 DB ──▶ Claude가 읽음
(세션 87개)   (에이전트)   (사실·질문)  (일괄, 이후 1문)  (~/.claude/me/)  (CLAUDE.md · CLAUDE.local.md)
```

- 활동 소스는 Claude Code 세션으로 시작한다. Codex 등 다른 소스를 붙일 수 있게 만든다.
- 저장은 `~/.claude/me/`. 마크다운 파일 하나 = 사실 하나. git에 올리지 않는다.
- 사실마다 출처 세션, 확인 여부, 회사/개인 구분, 확인일이 붙는다.
- 시크릿 값은 격리된 암호화 파일에 둔다. Claude는 그 파일을 읽을 수 없다. 맥락 DB에는 위치와 변수 이름만 남는다.
- Claude가 읽는 길은 둘: `~/.claude/CLAUDE.md`(일하는 방식) + 프로젝트 폴더의 `CLAUDE.local.md`(프로젝트 사정).

## 성공 기준

아무 프로젝트 폴더에서 새 세션을 열고 "이거 어떻게 띄워? 규칙은?"을 물으면 설명 없이 답한다.

## 활용 방향 (다음 단계)

- AI-DLC의 `team.md` · `project.md`를 이 DB에서 채운다 → practices-discovery가 다시 묻지 않는다
- Agent Factory 아바타 카드의 개인 실행 프로필을 이 DB에서 만든다
- 사람마다 쌓인 맥락 DB가 모이면 팀 맥락이 된다

맥락 DB 자체(`~/.claude/me/`)는 이 리포에 없다. 여기에는 도구·문서·시연만 둔다.
