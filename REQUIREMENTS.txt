# knows-me

## Requirements
1. 나의 데이터를 조회할 수 있는 모든 데이터가 구조화된 시스템
2. 아래 Source를 쉽게 가져올 수 있어야함
  - 에이전트 세션: Claude Code, Codex
  - 외부 시스템: Confluence, Jira, Notion, Gmail
  - 사진, 텍스트 파일, 오피스 파일
  - 카카오톡 대화
3. 데이터를 보충 하거나 구체화할 수단이 있어야 함
4. 데이터 저장 및 조회 시 기본적인 보안 제공
5. 데이터를 제공할 수 있는 다양한 인터페이스를 제공

## HLD
Features
- Desktop App
  - 인터뷰 Queue: 에이전트가 Source로 부터 얻은 데이터를 명확하게 할 필요가 있는 것, 더 알면 좋을 것 등 의문을 기록해두는 Queue.
      해당 큐의 아이템은 유저가 추후에 인터뷰 세션을 열어서 Answer을 제공.
  - Knowlege DB: Sources + 질의 응답 세션을 통해 구체화 된 정보를 구축한 Database
User Interface
- Desktop App
  - 대시보드
  - 싸이월드 (?)
  - Knowlege DB: Graph DB
- Web Server
  - Share view
- 인터페이스 데모
  - Chat UI / Rest API
    - 나 대신 네트워킹을 해줘 (메일 / 메신저 / DSDN 게시글 작성 등)
    - (심화) 나 대신 회의 참석 (회의 내용 이해, 페르소나)
