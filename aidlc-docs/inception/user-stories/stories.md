# User Stories (knows-me)

> **구조**: Epic-Based + Feature 정렬 (Epic = 요구사항 FR 그룹). **범위**: MVP(§5.1)만.
> **수용 기준**: Given-When-Then. **세분도**: 중간(기능 단위). **INVEST** 준수.
> **페르소나**: 모두 P1 소유자(Owner). P2 제3자 소비자는 MVP 스토리 없음(향후).
> 각 스토리에 관련 FR(추적성)과 PBT 대상(NFR-8) 표시.

---

## EPIC E1 — 소스 수집 (Ingestion) 〔FR-1〕

### US-1.1 에이전트 세션 자동 수집(배치)
**As** 소유자, **I want** 앱이 Claude Code·Codex 세션을 주기적으로 자동 수집하기를, **so that** 내가 뭘 했는지 직접 입력하지 않아도 맥락이 쌓인다.
- **AC1** — Given 세션 저장 위치에 신규 트랜스크립트가 있고, When 주기적 배치가 실행되면, Then 신규분만(이미 수집된 것 제외) 가공 대기 항목으로 등록된다.
- **AC2** — Given 이미 수집한 세션을 다시 스캔할 때, When 배치가 재실행되면, Then 중복 없이 아무 것도 새로 추가되지 않는다(멱등).
- **AC3** — Given 세션 저장 위치를 읽을 수 없을 때, When 배치가 실행되면, Then 오류를 기록하고 다음 주기에 재시도하며 앱은 계속 동작한다.
- **INVEST**: 독립적(단일 소스), 테스트가능(멱등/증분). **PBT**: 증분 수집 멱등성(불변식).
- **추적성**: FR-1.1, D5, NFR-5.

### US-1.2 세션 수집 수동 트리거
**As** 소유자, **I want** "지금 수집" 버튼으로 즉시 세션 수집을 돌리기를, **so that** 방금 끝낸 작업을 기다리지 않고 반영한다.
- **AC1** — Given 앱이 실행 중일 때, When "지금 수집"을 누르면, Then 배치와 동일한 증분 수집이 즉시 1회 수행되고 진행/결과가 표시된다.
- **AC2** — Given 수집이 진행 중일 때, When 다시 누르면, Then 중복 실행 없이 진행 중임을 알린다.
- **INVEST**: 작음. **추적성**: FR-1.1(수동), D5.

### US-1.3 Notion 연동 수집
**As** 소유자, **I want** 내 Notion 콘텐츠를 연동해 수집하기를, **so that** 세션에 없는 문서 맥락도 확보된다.
- **AC1** — Given Notion 인증이 설정되어 있고, When 동기화가 실행되면, Then "내 것"으로 필터된 페이지가 증분 수집된다.
- **AC2** — Given 인증이 없거나 만료됐을 때, When 동기화하면, Then 재인증을 유도하고 자격증명은 암호화 저장된다(FR-5.4).
- **AC3** — Given 이전 동기화 이후 변경이 없을 때, When 재동기화하면, Then 신규/변경분만 반영한다.
- **INVEST**: 독립적(커넥터 플러그형). **추적성**: FR-1.2, D6, NFR-7.

### US-1.4 Gmail 연동 수집
**As** 소유자, **I want** 내가 주고받은 메일을 연동해 수집하기를, **so that** 업무 흐름·연락 맥락이 확보된다.
- **AC1** — Given Gmail 인증이 설정되어 있고, When 동기화가 실행되면, Then 내가 보낸/받은 메일이 "내 것" 기준으로 증분 수집된다.
- **AC2** — Given 민감할 수 있는 메일 본문일 때, When 가공 단계로 넘길 때, Then 마스킹 대상(US-2.2)으로 표시된다.
- **INVEST**: 독립적. **추적성**: FR-1.2, D6.

### US-1.5 파일 수집(폴더 감시·수동 업로드·이미지 비전)
**As** 소유자, **I want** 지정 폴더의 파일을 자동 감시하고 필요 시 수동 업로드하기를, **so that** 사진·문서 형태의 맥락도 들어온다.
- **AC1** — Given 감시 폴더에 새 파일이 생기면, When 앱이 이를 감지하면, Then 텍스트/오피스는 본문 파싱, 이미지는 비전으로 텍스트 맥락을 추출해 가공 대기로 등록한다.
- **AC2** — Given 감시 밖의 파일을 넣고 싶을 때, When 앱에서 수동 업로드하면, Then 동일한 가공 파이프라인으로 처리된다.
- **AC3** — Given 지원하지 않는 형식일 때, When 수집되면, Then 건너뛰고 사유를 기록한다.
- **INVEST**: 테스트가능. **추적성**: FR-1.3, A1.

## EPIC E2 — 가공 & 마스킹 (Processing) 〔FR-2〕

### US-2.1 요약·분류(반복/필요한 것만)
**As** 소유자, **I want** 원본이 아니라 요약·분류된 맥락만 쌓이기를, **so that** 메모리가 로그가 아니라 쓸모 있는 지식이 된다.
- **AC1** — Given 수집된 원본이 대기 중일 때, When 가공이 실행되면, Then 반복되는/필요한 항목만 요약·분류되어 사실 후보로 전환된다.
- **AC2** — Given 일회성·잡음으로 판정된 항목일 때, When 가공되면, Then Knowledge DB에 저장되지 않고 걸러진다.
- **AC3** — Given 불확실하거나 확인이 필요한 항목일 때, When 가공되면, Then 인터뷰 Queue 아이템으로 이관된다(→E4).
- **INVEST**: 가치. **추적성**: FR-2.1, FR-2.2.

### US-2.2 클라우드 전송 전 마스킹
**As** 소유자, **I want** LLM에 보내기 전에 식별정보·비밀이 제거되기를, **so that** 클라우드를 쓰더라도 민감정보 노출을 최소화한다.
- **AC1** — Given 이름·이메일·전화·계정·토큰 등 식별정보가 포함된 텍스트일 때, When 마스킹이 적용되면, Then 해당 정보가 치환/제거된 뒤에만 외부 LLM으로 전송된다.
- **AC2** — Given 마스킹된 텍스트를 복원해야 할 때, When 로컬에서 매핑을 적용하면, Then 원문 의미가 로컬 범위에서만 복원된다(원문·매핑은 기기 밖으로 나가지 않음).
- **AC3** — Given 마스킹 규칙이 특정 패턴을 놓칠 때, When 검출되면, Then 규칙을 보강할 수 있도록 로깅된다.
- **INVEST**: 테스트가능. **PBT**: 마스킹 불변식("출력에 원본 식별정보가 남지 않는다"), 마스킹↔복원 왕복.
- **추적성**: FR-2.3, D2, NFR-2, R1.

### US-2.3 전송 투명성
**As** 소유자, **I want** 어떤 데이터가 외부 LLM으로 나가는지 볼 수 있기를, **so that** 무엇이 전송되는지 통제·인지할 수 있다.
- **AC1** — Given 외부 LLM 호출이 발생할 때, When 호출이 이뤄지면, Then 전송된(마스킹 후) 요약/대상이 사용자에게 확인 가능한 형태로 기록된다.
- **INVEST**: 작음. **추적성**: NFR-2.

## EPIC E3 — Knowledge DB (파일 기반 "LLM 위키") 〔FR-3〕

### US-3.1 사실 문서 저장(메타데이터 포함)
**As** 소유자, **I want** 확인된 사실이 하나의 문서로 저장되기를, **so that** 사람이 읽고 백업·편집할 수 있는 위키가 된다.
- **AC1** — Given 확인/답변된 사실일 때, When 저장되면, Then 사실 하나 = 문서 하나(마크다운/JSON)로 기록되고 문서 간 링크가 유지된다.
- **AC2** — Given 사실을 저장할 때, When 기록되면, Then 출처(소스·수집시각)·확인 여부·회사/개인 구분·확인일 메타데이터가 함께 저장된다.
- **AC3** — Given 미확인 항목일 때, When 저장을 시도하면, Then Knowledge DB에는 반영되지 않는다(확인된 것만).
- **INVEST**: 가치. **PBT**: 사실 모델 ↔ 문서 직렬화/역직렬화 왕복.
- **추적성**: FR-3.1, FR-3.2, NFR-6.

### US-3.2 변경 이력 보존
**As** 소유자, **I want** 사실이 바뀌어도 이전 값이 남기를, **so that** 언제 무엇이 어떻게 바뀌었는지 추적된다.
- **AC1** — Given 기존 사실과 상충/갱신되는 새 값일 때, When 갱신되면, Then 덮어쓰지 않고 이력이 보존되며 현재값을 식별할 수 있다.
- **AC2** — Given 특정 사실을 볼 때, When 이력을 조회하면, Then 시간순 변경 내역이 표시된다.
- **INVEST**: 테스트가능. **추적성**: FR-3.3.

### US-3.3 검색·조회
**As** 소유자, **I want** 저장된 사실을 빠르게 검색·조회하기를, **so that** 필요한 맥락을 즉시 찾는다.
- **AC1** — Given 수천~수만 사실이 있을 때, When 키워드/필터로 검색하면, Then 반응성 있게 결과가 반환된다(NFR-4).
- **AC2** — Given 회사/개인 등 메타데이터로 좁힐 때, When 필터하면, Then 해당 조건의 사실만 반환된다.
- **INVEST**: 독립적. **추적성**: FR-3.1(인덱스), NFR-4.

## EPIC E4 — 인터뷰 Queue 〔FR-4〕

### US-4.1 Queue 아이템 자동 생성(확인형·심화형)
**As** 소유자, **I want** 수집·가공 중 확인이 필요한 것과 더 알면 좋을 것이 Queue에 쌓이기를, **so that** 세션에 없는 맥락도 되물어 채운다.
- **AC1** — Given 가공에서 사실 후보가 나올 때, When Queue에 적재되면, Then "확인형"(진위 확인) 아이템으로 만들어진다.
- **AC2** — Given 가설을 세울 만한 정보가 있을 때, When Queue에 적재되면, Then "심화형"(파고드는 질문) 아이템으로 만들어진다.
- **AC3** — Given 심화형에 답이 달릴 때, When 답의 키워드가 새 가설을 낳으면, Then 후속 질문이 이어서 생성될 수 있다.
- **INVEST**: 가치. **추적성**: FR-4.1.

### US-4.2 전환 없는 답변 UX(선택지 + 직접입력)
**As** 소유자, **I want** Queue 화면 안에서 화면 전환 없이 원할 때 답하기를, **so that** 부담 없이 흐름 끊김 없이 맥락을 채운다.
- **AC1** — Given Queue에 아이템이 있을 때, When 사용자가 답하려 하면, Then 같은 화면에서(전환 없이) 답변 선택지와 직접 입력이 모두 제공된다.
- **AC2** — Given 사용자가 답하지 않을 때, When Queue를 방치하면, Then 강제되지 않고 아이템은 대기 상태로 남는다.
- **AC3** — Given 아이템에 답이 확정될 때, When 저장되면, Then 해당 사실이 Knowledge DB에 반영된다(→US-3.1).
- **INVEST**: 테스트가능(핵심 UX 제약). **추적성**: FR-4.3.

### US-4.3 우선순위·만료
**As** 소유자, **I want** 중요한 질문이 먼저 뜨고 오래된/반복 질문은 정리되기를, **so that** Queue가 잡음으로 넘치지 않는다.
- **AC1** — Given 여러 아이템이 있을 때, When Queue를 볼 때, Then 우선순위 순으로 정렬되어 표시된다.
- **AC2** — Given 오래되었거나 반복되는 아이템일 때, When 만료 조건에 걸리면, Then 정리(만료/억제)된다.
- **INVEST**: 작음. **추적성**: FR-4.2.

## EPIC E5 — 인터페이스(조회·시각화) 〔FR-6〕

### US-5.1 대시보드
**As** 소유자, **I want** 수집 현황·대기 Queue 수·최근 확정 사실을 한눈에 보기를, **so that** 시스템 상태를 즉시 파악한다.
- **AC1** — Given 앱을 열 때, When 대시보드가 로드되면, Then 수집 현황, 대기 Queue 개수, 최근 확정 사실이 표시된다.
- **AC2** — Given 상태가 변할 때, When 대시보드를 볼 때, Then 최신 수치가 반영된다.
- **INVEST**: 독립적. **추적성**: FR-6.1.

### US-5.2 미니홈피("싸이월드") 뷰
**As** 소유자, **I want** 확정된 나의 맥락을 미니홈피 스타일 한 화면으로 보기를, **so that** "나"를 직관적으로 조망한다.
- **AC1** — Given 확정된 사실들이 있을 때, When 미니홈피 뷰를 열면, Then 나를 대표하는 맥락이 미니홈피 스타일로 시각화된다.
- **INVEST**: 독립적(뷰). **추적성**: FR-6.2.

### US-5.3 지식 그래프 뷰
**As** 소유자, **I want** 사실 문서의 링크를 그래프로 탐색하기를, **so that** 맥락 간 관계를 이해한다.
- **AC1** — Given 문서 간 링크가 있을 때, When 그래프 뷰를 열면, Then 사실이 노드, 링크가 엣지로 표시되고 탐색할 수 있다.
- **INVEST**: 독립적. **추적성**: FR-6.3, FR-3.1.

## EPIC E6 — 페르소나 챗 & 로컬 API 〔FR-6.4, FR-7〕

### US-6.1 페르소나 챗(소유자 대화)
**As** 소유자, **I want** 나의 맥락 기반 페르소나와 대화하기를, **so that** 내가 아는 것을 대화로 꺼내 쓴다.
- **AC1** — Given 확정된 맥락이 있을 때, When 챗에서 질문하면, Then 페르소나가 나의 맥락에 근거해 답한다.
- **AC2** — Given 외부 LLM 호출이 필요할 때, When 응답을 생성하면, Then 마스킹 정책(US-2.2)이 적용된다.
- **INVEST**: 가치. **추적성**: FR-6.4, D2.

### US-6.2 "나 대신 네트워킹" 초안 작성(로컬 API)
**As** 소유자, **I want** 로컬 API로 메일/메신저/게시글 초안을 나 대신 작성하게 하기를, **so that** 반복적인 커뮤니케이션을 위임한다.
- **AC1** — Given 앱이 실행 중이고 로컬 서버가 켜져 있을 때, When 로컬 API로 초안 작성을 요청하면, Then 나의 페르소나로 초안이 생성되어 반환된다.
- **AC2** — Given MVP 단계일 때, When 외부에서 접근을 시도하면, Then 로컬 전용이라 외부 노출이 없다(D7).
- **INVEST**: 가치(최우선 기능). **추적성**: FR-7.1, FR-7.2, D7, D8.

## EPIC E7 — 보안 & 온보딩 〔FR-5〕

### US-7.1 최초 설치 비밀번호 설정 & 암호화 초기화
**As** 소유자, **I want** 설치 시 비밀번호를 정하면 저장이 암호화되기를, **so that** 로컬 데이터가 보호된다.
- **AC1** — Given 첫 실행일 때, When 비밀번호를 설정하면, Then 키 유도 함수(Argon2/PBKDF2)로 키가 생성되고 저장 데이터가 대칭키(AES-256-GCM)로 암호화된다.
- **AC2** — Given 키를 생성할 때, When 저장하면, Then 평문 데이터 키는 디스크에 저장되지 않는다.
- **INVEST**: 테스트가능. **PBT**: 암호화↔복호화 왕복(PBT-02).
- **추적성**: FR-5.1~5.3, R1.

### US-7.2 잠금 해제(키 재유도)
**As** 소유자, **I want** 앱 실행 시 비밀번호로 잠금을 해제하기를, **so that** 정당한 사용자만 데이터에 접근한다.
- **AC1** — Given 암호화가 초기화된 상태일 때, When 올바른 비밀번호를 입력하면, Then 키가 재유도되어 데이터에 접근할 수 있다.
- **AC2** — Given 틀린 비밀번호일 때, When 입력하면, Then 복호화가 실패하고 데이터가 노출되지 않는다.
- **INVEST**: 작음. **추적성**: FR-5.3.

### US-7.3 외부 자격증명 암호화 보관
**As** 소유자, **I want** Notion·Gmail 등 자격증명이 암호화 보관되기를, **so that** 연동 토큰이 유출되지 않는다.
- **AC1** — Given 외부 시스템 인증을 마칠 때, When 자격증명이 저장되면, Then 암호화되어 보관된다.
- **AC2** — Given 자격증명이 필요할 때, When 동기화가 이를 사용하면, Then 메모리 내에서만 복호화되어 사용된다.
- **INVEST**: 독립적. **추적성**: FR-5.4, FR-1.2.
