# U4 Business Rules (Interface & Persona)

> ID 규칙: `BR-P*`=페르소나, `BR-A*`=로컬 API, `BR-V*`=뷰/조회, `BR-E*`=오류/저하

## 페르소나 (US-6.1, US-6.2)

| ID | 규칙 | 근거 | 위반 시 |
|---|---|---|---|
| BR-P1 | `PersonaContext`에는 **확정된(`metadata.confirmed == true`) 사실만** 들어간다. 미확정 후보는 근거로 쓰지 않는다. | US-6.1 AC1, US-3.x 확정 경로 | 해당 사실 제외 (조용히 드롭, 오류 아님) |
| BR-P2 | **모든 외부 LLM 호출은 `Masker.mask()`를 통과한 텍스트만** 전달한다. 소유자 데이터(맥락 본문 + 사용자 입력)는 전부 `user_document` 한 곳에 모아 **단일 `mask()` 호출**로 처리하고, `system`은 소유자 데이터를 포함하지 않는 정적 템플릿으로 유지한다. *(개정 근거: system/user를 따로 마스킹하면 두 `UnmaskMap` 사이에서 placeholder 네임스페이스가 충돌할 수 있다. 소유자 데이터를 한쪽으로 몰아 그 가능성 자체를 없앤다 — 마스킹 대상 범위는 동일하다.)* | US-6.1 AC2, D2, NFR-2, R1 | 설계 위반 — 타입(`MaskedText`)으로 컴파일 타임 차단 |
| BR-P2a | `system` 프롬프트에는 어떤 소유자 데이터도 넣지 않는다. 위반 시 그 데이터는 마스킹되지 않은 채 전송된다. | NFR-2 | 예제 테스트 `system_prompt_carries_no_owner_data`로 고정 |
| BR-P3 | 복원(`unmask`)은 **로컬에서만** 수행한다. `UnmaskMap`은 요청 처리 중 메모리에만 존재하며 디스크·네트워크로 나가지 않는다. | NFR-2, R1 | 설계 위반 |
| BR-P4 | 맥락이 비어 있으면(`entries.is_empty()`) **LLM을 호출하지 않고** "확정된 맥락이 없어 답할 수 없다"는 결정적 메시지를 반환한다. | 환각 방지, NFR-2(불필요 전송 차단) | — |
| BR-P5 | 맥락 사실 수는 `ContextSelection.max_facts`(기본 12)를 넘지 않는다. 초과분은 연관도 낮은 순으로 절단한다. | NFR-4(반응성), 토큰 비용 | 절단 |
| BR-P6 | LLM 실패(`AppError::External`)는 **삼키지 않고 전파**한다. 조회 기능은 영향을 받지 않는다. | NFR-3 부분 저하 | 오류 전파 |
| BR-P7 | 맥락 정렬은 **전순서**여야 한다: `relevance desc` → `confirmed_at desc` → `FactId asc`. 같은 입력은 항상 같은 맥락을 만든다. | 재현성, 테스트 가능성 | — |
| BR-P8 | 초안 종류(`DraftKind`)별 출력 형식 지시를 system 프롬프트에 포함한다(Email=제목+본문/격식, Message=짧은 메신저 톤, Post=1인칭 공개글). | FR-7.2 | — |

## 로컬 API (US-6.2, D7, D8)

| ID | 규칙 | 근거 | 위반 시 |
|---|---|---|---|
| BR-A1 | 리스너는 **`127.0.0.1`에만 바인딩**한다. `0.0.0.0`/공인 IP 바인딩 금지. | US-6.2 AC2, D7, FR-7.1 | 시작 거부 |
| BR-A2 | `Host` 헤더가 loopback(`127.0.0.1`/`localhost`/`[::1]`)이 아니면 **403**으로 거부한다(DNS rebinding 방어). | D7 | 403 |
| BR-A3 | 로컬 API는 **PersonaService를 위임만** 한다. 자체 비즈니스 로직·별도 맥락 규칙을 두지 않는다. | 단일 경로 원칙 | 설계 위반 |
| BR-A4 | 서버는 **앱 실행 중에만** 살아 있다. `stop()` 시 리스너를 닫는다. | FR-7.1 | — |
| BR-A5 | MVP는 인증·API 키를 요구하지 않는다(D7). 원격 노출은 범위 외(FR-7.3). | D7 | — |
| BR-A6 | 오류 매핑은 고정이다: `Locked`→423, `InvalidInput`→400, `NotFound`→404, `External`→502, 그 외→500. | 일관된 클라이언트 계약 | — |
| BR-A7 | 기본 포트 8765. 사용 중이면 8765..8785에서 첫 가용 포트를 쓰고 **실제 포트를 반환**한다. | 사용성 | 범위 내 가용 포트 없으면 `Io` 오류 |

## 뷰/조회 (US-5.1, US-5.2, US-5.3)

| ID | 규칙 | 근거 | 위반 시 |
|---|---|---|---|
| BR-V1 | 대시보드 수치는 **U3의 `dashboard()` 결과를 그대로** 쓴다. U4가 재집계하지 않는다. | 유닛 경계, 단일 출처 | 설계 위반 |
| BR-V2 | 미니홈피 하이라이트 = 확정 사실을 `(연결도 desc, 제목 asc, id asc)`로 정렬한 상위 `limit`(기본 9). 확정되지 않은 사실은 제외한다. *(개정 근거: 원래 두 번째 키였던 `확정일 desc`를 제거했다. 랭킹은 `FactSummary`에서 수행되는데 이 타입에는 타임스탬프가 없어, 확정일을 쓰려면 사실마다 `get()`을 호출해야 하고 그것이 U4-NFR-P2를 깨뜨리는 N+1이다. `FactSummary`에 `confirmed_at`이 추가되면 두 번째 키로 복원한다 — integration-handoff에 요청 기재.)* | US-5.2 AC1, U4-NFR-P2 | 제외 |
| BR-V3 | 그래프는 **양 끝 노드가 모두 존재하는 엣지만** 표시한다(dangling edge 제거). 중복 엣지는 1개로 합친다. | US-5.3 AC1, 렌더 정확성 | 엣지 제거 |
| BR-V4 | 그래프 레이아웃은 **결정적**이다. 난수·현재 시각·삽입 순서에 의존하지 않는다. | 테스트 가능성, 사용자 혼란 방지 | — |
| BR-V5 | 모든 노드 좌표는 뷰박스 `[0,w] x [0,h]` 안에 있어야 한다(클램프). | 렌더 정확성 | 클램프 |
| BR-V6 | 데이터가 비어 있는 뷰는 **빈 상태(empty state)** 를 명시적으로 표시한다(오류로 취급하지 않음). | 사용성(심사 기준 ⑤) | — |
| BR-V7 | 뷰는 상태를 소유하지 않고 `KnowsMeApi`를 통한 command/query만 호출한다. | services.md 오케스트레이션 원칙 | 설계 위반 |
| BR-V8 | 그래프/미니홈피/대시보드 조회는 **LLM에 의존하지 않는다** — 오프라인에서도 동작해야 한다. | NFR-3 | — |

## 오류 처리 / 저하 (NFR-3)

| ID | 규칙 |
|---|---|
| BR-E1 | 잠금 상태(`AppError::Locked`)에서는 조회·페르소나 모두 거부되고, UI는 "잠금 해제 필요"를 표시한다(잠금 해제 UI는 U1 소유이므로 U4는 안내만 한다). |
| BR-E2 | 네트워크/LLM 오류는 **뷰 단위로 국소화**한다. 챗 실패가 대시보드·그래프를 망가뜨리지 않는다. |
| BR-E3 | 모든 U4 오류는 `AppError`로 정규화해 반환한다. 문자열 오류를 그대로 노출하지 않는다. |
| BR-E4 | 프론트엔드는 각 뷰마다 `loading / ready / empty / error` 4상태를 명시적으로 가진다. |

## 보안 (횡단)

| ID | 규칙 |
|---|---|
| BR-S1 | U4 코드에 **시크릿·API 키·토큰을 하드코딩하지 않는다**. LLM 자격증명은 U1 Vault/환경변수 경유(심사 기준 ⑥). |
| BR-S2 | `UnmaskMap`·원문 사실 본문을 로그로 출력하지 않는다. |
| BR-S3 | 로컬 API 응답에 내부 경로·스택 트레이스를 포함하지 않는다. |
